% RESUMEN
\section*{Resumen}
\addcontentsline{toc}{section}{Resumen}
En el presente documento se detalla el diseño y desarrollo de un programa en lenguaje C que implementa un sistema de inicio de sesión mediante una interfaz basada en texto construida con la biblioteca ncurses. Se documentan los métodos de cifrado para contraseñas, la validación de entrada por parte del usuario y el almacenamiento persistente mediante archivos del sistema. Adicionalmente, se comprueba el cumplimiento de las reglas de negocio establecidas, como la ejecución sin gestores de bases de datos, sin el uso de sockets y la compilación exitosa sin errores usando Makefile.

% INTRODUCCIÓN
\section{Introducción}
El control de acceso es un componente crucial en la administración de sistemas operativos y aplicaciones de software. La presente práctica tiene como objetivo diseñar e implementar un inicio de sesión capaz de solicitar, validar, cifrar y almacenar de manera persistente las credenciales de usuarios. A través del lenguaje C y la biblioteca ncurses, se garantiza una interfaz visual limpia en terminal. Debido a las reglas establecidas en este proyecto, se omiten las arquitecturas con bases de datos relacionales y comunicaciones vía sockets, delegando la gestión y recuperación de credenciales netamente al sistema de archivos local de manera segura.
